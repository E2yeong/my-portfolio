# Portfolio

Source for my personal portfolio site: **https://e2yeong.github.io/my-portfolio/**

A single-page site with an overview of my background, skills, projects and certifications, and links to my study-note sites.

## Built with

Plain HTML, CSS and JavaScript (no framework or build step), hosted on GitHub Pages.

- `index.html`: page content and sections (About, Skills, Projects, Contact)
- `style.css`: layout, responsive design and animations
- `script.js`: navigation, scroll effects and the project / certification tabs

## Run locally

Clone the repository and open `index.html` in a browser.
